# gauntlet-L01-hello-greeter

This program asks for the user's first name, last name and then formats it properly by removing spaces and changing the case to title case. It also asks for the user's birth year and then calculates their approximate age by using the current year from datetime standardlibrary. It then prints a personalised greeting by using the user's full name and their age. All inputs are validated and possible errors are caught using try...except.
